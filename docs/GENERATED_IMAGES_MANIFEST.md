# Manifiesto de imagenes existentes

## Estado y procedencia

`public/images` contiene 44 archivos WebP. Son placeholders abstractos creados programaticamente, no fotografias generadas, no salida fotorrealista de un generador y no representaciones de personas, profesionales, pacientes, instalaciones ni edificios de la clinica. No deben publicarse o describirse como fotos de la Clinica Medica Santa Ana.

No hay un generador de imagen ni un MCP de generacion expuesto. Tampoco existe un registro verificable de modelo, prompt base o prompt individual para estos archivos; por ello el estado de prompt de todo el inventario es **no registrado/no aplica a generacion programatica**. Las descripciones siguientes documentan la funcion visual inferida por nombre y uso, no atribuyen una escena real.

Los nombres exactos usados actualmente por la UI existen: `clinic/clinic-hero.webp`, `clinic/clinic-care.webp`, `clinic/clinic-about.webp`, `clinic/clinic-contact.webp`, `doctors/portrait-placeholder.webp` y los 12 fallbacks existentes de especialidades. Los demas archivos son placeholders disponibles, aunque no todos tienen uso directo localizado en las pantallas actuales.

## Reglas de uso y actualizacion

- Mantener textos de interfaz como `temporal`, `abstracto` o equivalentes mientras se usen estos archivos.
- No cambiar el alt para afirmar que aparece la clinica, un medico, un paciente, una sala o un procedimiento real.
- No usar el nombre del archivo como evidencia de un servicio ofrecido.
- Registrar para cualquier reemplazo: ruta, dimensiones, bytes, SHA-256, autor/herramienta, prompt si aplica, fecha, licencia, aprobador, privacidad, accesibilidad y estado.
- No llamar a estos archivos "fotos generadas por IA". La evidencia disponible solo permite describirlos como placeholders abstractos generados programaticamente.
- El brief y el flujo de aprobacion futuro se mantienen en `IMAGE_GENERATION_PLAN.md`; sus afirmaciones de que no habia imagenes quedaron superadas para placeholders, no para fotografias aprobadas.
